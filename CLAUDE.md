## Project

CFOP (Rubik's cube speedsolving method) tutorial app. Tauri v2 shell with a React 19 + TypeScript + Vite frontend and a Rust backend. Currently the unmodified `create-tauri-app` scaffold (the `greet` demo is still in place). Intended targets: desktop and mobile.

## Commands

```
npm install                  # install frontend + Tauri CLI
npm run tauri dev            # run desktop app (starts Vite on :1420 automatically)
npm run dev                  # frontend only in a browser (Tauri APIs like invoke() won't work)
npm run build                # type-check (tsc) + Vite build into dist/
npm run tauri build          # production desktop bundle (installers in src-tauri/target/release/bundle/)
npm run tauri android init   # one-time Android project generation (needs Android Studio + NDK)
npm run tauri android dev
npm run tauri ios init       # macOS + Xcode only
```

Rust-side checks, run from `src-tauri/`: `cargo check`, `cargo clippy`, `cargo test`.

No test runner, linter, or formatter is configured for the frontend yet. `npm run build` is the only type check.

## Architecture

- **Frontend** (`src/`): React app entered via `src/main.tsx`. Calls Rust through `invoke("<command>", args)` from `@tauri-apps/api/core`.
- **Backend** (`src-tauri/src/`): All app logic lives in `lib.rs` (crate `cfop_tutorial_lib`); `main.rs` only calls `run()`. Keep it this way: the `#[cfg_attr(mobile, tauri::mobile_entry_point)]` on `run()` is what mobile builds use as their entry point, so code placed in `main.rs` won't run on Android/iOS.
- **Adding a Rust command**: define a `#[tauri::command]` fn, then register it in `tauri::generate_handler![...]` in `lib.rs`. Argument names in `invoke` are camelCase on the JS side.
- **Plugins**: need four things: the Cargo dependency, `.plugin(...)` in `lib.rs`, the npm package, and a permission entry in `src-tauri/capabilities/default.json`. A missing capability permission fails at runtime, not compile time.
- **Config**: `src-tauri/tauri.conf.json` ties the two halves together (`devUrl` http://localhost:1420, `frontendDist` ../dist). Vite uses `strictPort` on 1420 and reads `TAURI_DEV_HOST` for mobile dev on a physical device; don't change the port in one place without the other.
- `src-tauri/gen/` is generated by the Tauri CLI; don't edit it by hand.
